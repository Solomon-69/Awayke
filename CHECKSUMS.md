# Download checksums (SHA-256)

Fingerprints of the current release downloads (Awayke 1.6.0). If a file you downloaded gives a different fingerprint, do not open it.

```
b50df2601e0cf1bd50d846efee3af0e9ea1f7ee0cdcea851ad24ffcf712df56a  Awayke.dmg
10dd4f98ff233076aa19be9b36e828d0c09cc3c2e28b19941b4bf2ca2470444c  Awayke-1.6.0.zip
af64e4c6634ec96d320422c03c8e69105a6d950358f9e7b702b59eee696a7024  Awayke-windows.zip
```

Check on Mac: `shasum -a 256 <file>`. Check on Windows: `certutil -hashfile <file> SHA256`.

Release: [v1.6.0](https://github.com/Solomon-69/Awayke/releases/tag/v1.6.0) (Awayke.dmg, Awayke-1.6.0.zip, Awayke-windows.zip). A SHA256SUMS file for the Mac files is attached to the release too.

The apps are not signed yet; see the "Unsigned apps" section of the README.
